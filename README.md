# 霜语渡口

《龙与地下城》5e（2024 规则）。过河不要钱，只要一样你带得走、但不想给的东西。上个月过河的十一人，货回来了，人没有。

- **人数**：3–5 人（推荐 3–4 级）
- **时长**：约 150 分钟
- **结构**：3 章 / 15 节点 / 4 个结局
- **内容**：世界书 18 条（9 条公开 / 9 条守秘人专属），地图地点 10 个
- **适用规则**：D&D 2024（`core:dnd2024`）

## 结构

| 部分 | 内容 |
|---|---|
| 第一章：渡口客栈 | 说不出名字的护卫、灰袍法师、河岸水下的窗 |
| 第二章：过河 | 驳船与舱壁、六十七张货签、山口的风 |
| 第三章：最后一趟 | 四个结局 |

## 守秘人要点

1. **那句「喂——」要真的说出口。** 在桌上说，用正常音量，说完停三秒。玩家会自己安静下来。越日常越好。

2. **老斯诺不是反派。** 他是第三代摆渡人，自己也交过名字。他的悲剧是：必须让别人交，才能维持这条路。

3. **水下那些光要提前给。** 先让玩家看见「像村子的窗」，结局时再让他们看着这些光熄灭——「像下班」这个比喻，比任何恐怖描写都重。

## 这个模组在讲什么

关键机制：应声不是「回答」，是「承认这个名字属于你」。所以替别人应也算数，应不认识的名字不算。
